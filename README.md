SmartMarkr 智签管家 - 产品介绍

📋 产品概述

SmartMarkr 智签管家：专业浏览器书签管理扩展，高效规整海量书签。

版本信息：v1.0.0（2026年1月发布），支持Chrome、Edge、Firefox等Chromium内核浏览器。


---
✨ 核心功能

1. 重复书签检测：精确/智能识别重复/相似书签，支持批量预览删除。

2. 智能归档：按类型/网站自动分类，支持自定义归档规则。

3. 书签清理：清理空文件夹、检测失效链接，支持批量操作。

4. 书签搜索：标题/URL全文检索，支持高级筛选与实时预览。

5. 数据导出：JSON/HTML格式（通用浏览器导入），本地备份更安全。


---
🎯 产品特色

- 高性能：异步处理，支持千级书签高效管理，低资源占用。

- 现代化界面：简洁直观，操作流程清晰，视觉反馈明确。

- 隐私保护：100%本地处理，零数据上传，开源透明可审查。

- 国际化支持：中英文双语界面，兼容多语言扩展。


---
📦 安装方式

1. Chrome应用店（推荐）：搜索“SmartMarkr”，点击“添加至Chrome”即可。

2. 本地加载（开发模式）：下载文件后打开浏览器扩展页（Chrome/Edge对应地址），开启开发者模式，加载已解压文件。

3. Firefox安装：下载专用安装包，通过附加组件管理器“从文件安装”。


---
🎮 使用指南

点击工具栏图标启动，在新标签页进入管理界面，核心操作如下：

- 重复检测与清理：选择检测类型→开始检测→勾选删除。

- 智能归档：选择归档方式→执行归档，系统自动整理。

- 书签搜索/导出：进入对应模块，输入关键词筛选或点击导出按钮操作。


---
🛠️ 技术架构

核心技术：Manifest V3、原生JavaScript、Chrome Bookmarks API、响应式CSS。

项目结构：含后台脚本、图标/资源文件、业务脚本、样式文件及配置文件。
