# SmartMarkr 智签管家 - 产品介绍

## 📋 产品概述

**SmartMarkr 智签管家**是一款专业的浏览器书签管理扩展程序，致力于帮助用户高效管理海量书签，让书签井井有条。

### 版本信息
- **当前版本**: 1.0.0
- **发布日期**: 2026年1月
- **支持浏览器**: Chrome、Edge、Firefox 等 Chromium 内核浏览器

---

## ✨ 核心功能

### 1️⃣ 重复书签检测
- **精确检测**: 完全相同的 URL 自动识别
- **智能检测**: 相似标题和 URL 的智能匹配
- **批量处理**: 一键删除重复书签，支持预览

### 2️⃣ 智能归档
- **按类型归档**: 自动分类到技术、社交、购物等预设类别
- **按网站归档**: 将同一网站的书签集中管理
- **自定义规则**: 支持添加自定义分类规则

### 3️⃣ 书签清理
- **空文件夹清理**: 自动清理无用的空文件夹
- **异常链接检测**: 识别失效或格式异常的书签
- **批量删除**: 支持多选批量操作

### 4️⃣ 书签搜索
- **全文搜索**: 支持标题和 URL 全文检索
- **高级筛选**: 支持大小写敏感、文本纯化等选项
- **实时预览**: 搜索结果实时显示

### 5️⃣ 数据导出
- **HTML 导出**: 标准 Netscape 书签格式
- **兼容性强**: 浏览器通用导入格式
- **备份保护**: 数据安全可靠

## 📦 安装方式

### 方法一：Chrome 网上应用店安装（推荐）
1. 访问 [Chrome 网上应用店](https://chrome.google.com/webstore) 搜索"SmartMarkr"
2. 点击"添加至 Chrome"按钮
3. 在弹出窗口中点击"添加扩展程序"

### 方法二：本地加载（开发模式）
1. 下载扩展程序文件
2. 打开浏览器扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `1-加载此文件夹到浏览器` 目录

### 方法三：Firefox 安装
1. 下载 `Firefox-专用安装包.zip`
2. 打开 Firefox 附加组件管理器：`about:addons`
3. 点击齿轮图标，选择"从文件安装附加组件"
4. 选择下载的 zip 文件

## 🎮 使用指南

### 启动扩展
点击浏览器工具栏中的 SmartMarkr 图标，将在新标签页打开管理界面。

### 主要操作流程

#### 📍 重复检测与清理
1. 点击左侧导航栏的"重复检测"
2. 选择检测类型（精确/智能）
3. 点击"开始检测"按钮
4. 查看检测结果，勾选需要删除的书签
5. 点击"删除选中"执行清理

#### 📍 智能归档
1. 点击左侧导航栏的"智能归档"
2. 选择归档方式（按类型/按网站）
3. 点击"执行归档"
4. 系统自动创建文件夹并整理书签

#### 📍 书签搜索
1. 点击左侧导航栏的"书签搜索"
2. 输入搜索关键词
3. 选择搜索选项（标题/URL/大小写等）
4. 查看搜索结果

#### 📍 数据导出
1. 点击左侧导航栏的"数据导出"
2. 点击"导出为 HTML"按钮
3. 选择保存位置，完成导出

## 🛠️ 技术架构

### 核心技术栈
- **Manifest V3**: 最新 Chrome 扩展标准
- **原生 JavaScript**: 纯 JS 实现，无框架依赖

- **现代 CSS**: 响应式设计，优雅动画

## 💡 常见问题 FAQ

### Q1: 扩展安装后无法启用？
**A**: 请确保使用的是 Chromium 内核浏览器（Chrome、Edge 等），并且浏览器版本足够新（建议 Chrome 88+）。如果仍有问题，请尝试重新加载扩展。

### Q2: 删除重复书签后能否恢复？
**A**: 删除操作不可逆，建议在清理前使用"数据导出"功能备份书签。

### Q3: 归档功能会修改原有的书签吗？
**A**: 归档功能会将书签移动到新创建的文件夹中，不会删除或修改书签内容。

### Q4: 扩展会上传我的书签数据吗？
**A**: 绝对不会！SmartMarkr 100% 本地处理，不收集、不上传任何用户数据。

### Q5: 支持 Safari 浏览器吗？
**A**: 当前版本暂不支持 Safari，未来会考虑适配。
